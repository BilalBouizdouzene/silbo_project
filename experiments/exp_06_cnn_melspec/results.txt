Experiment: CNN on Log-Mel Spectrograms
=======================================

Description:
This experiment converts each audio file into a fixed-size log-mel spectrogram and trains a compact CNN for whistled sentence classification. The network is intentionally small because the dataset is limited.

Input representation:
- Sample rate: 16000 Hz
- Number of mel bins: 64
- Maximum number of frames: 256
- Input shape: (1, 64, 256)

Training configuration:
- Batch size: 8
- Max epochs: 60
- Early stopping patience: 10
- Learning rate: 0.001
- Weight decay: 0.0001
- Loss: CrossEntropyLoss with class weights

Cross-validation:
- StratifiedKFold with n_splits = 2
- Classes with fewer than 2 samples are excluded from evaluation
